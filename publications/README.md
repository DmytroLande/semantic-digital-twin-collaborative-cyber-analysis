# Publications

This directory contains publications that provide the scientific and methodological
foundation for the project.

The presented works introduce the concepts and methods used for constructing
the project's agent-based analytical workflow, including semantic digital twins,
Retrieval-Augmented Generation (RAG), Agentic AI, and structured multi-agent
prompt engineering.

## Included Publications

### A Methodology for System Analysis Based on Semantic Digital Twins of Problem Domains

Dmitry Lande, Leonard Strashnoy

The paper presents a methodology that integrates RAG, semantic digital twins,
bidirectional semantic graph construction, and Agentic AI into a unified
framework for system analysis.

The proposed approach provides the methodological basis for constructing and
analyzing the semantic digital twin used in this project.

---

### AgentFlow – No-Code Agent Framework Based on Logical Primitives

Dmitry Lande, Leonard Strashnoy

The paper introduces the AgentFlow framework for constructing structured
agent-based prompts using natural-language logical primitives and interacting
LLM agents.

AgentFlow provides the methodological basis for the agent prompts used in this
repository, including agent specialization, coordination, structured execution,
and aggregation of analytical results.

---

These publications constitute the scientific background of the project and
explain the methodological principles underlying the prompts, semantic models,
and experimental workflow presented in this repository.
